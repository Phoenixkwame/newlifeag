Import Members from CSV

Upload a CSV file with a header row. Only first_name and last_name are required - the rest are optional:

  • first_name, last_name - required
  • email, phone
  • role - member, staff, or admin (defaults to member)
  • household - matched by exact existing household name; left blank if no match
  • campus - matched by exact existing campus name; left blank if no match
  • is_active - yes/no (defaults to yes)

Every row that's created is a brand-new member - this never updates or merges with existing records, so re-uploading the same file twice will create duplicates.
